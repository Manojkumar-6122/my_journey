# Day 9 – PostHog Tracking

## What is an Event?

An event is an action performed by a user on a website or application. Examples include clicking a button, signing up, logging in, or completing a purchase. Events help developers understand how users interact with the application.

---

## What is a Funnel?

A funnel is a sequence of events that users are expected to complete. It helps measure how many users move from one step to the next and where they stop. For example:

Landing Page → Sign Up → Login → Purchase

Funnels help identify drop-off points and improve user experience.

---

## Why Every Client Site Ships with PostHog

PostHog helps businesses understand user behavior by tracking events and analyzing customer journeys. It provides insights into which features are used most, where users leave the application, and how changes affect user engagement. This information helps companies make better product decisions based on real user data.

---

## Key Takeaways

- Events record user actions.
- Funnels analyze user journeys.
- PostHog provides product analytics.
- Analytics help improve user experience and business decisions.
