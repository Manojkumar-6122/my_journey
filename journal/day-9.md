# Day 9 – Daily Learning Journal

## What I Learned Today

Today I learned how website analytics work by integrating PostHog into a Next.js application. I understood that PostHog is used to track user interactions, such as button clicks, page visits, and other custom events. I learned how to install the `posthog-js` package, initialize it in a Next.js project, and use the `capture()` method to send a custom event when a user clicks a button.

I also learned the concepts of events and funnels. Events represent individual user actions, while funnels help analyze the user's journey through multiple steps, such as visiting a landing page, signing up, and completing a purchase. These insights help businesses improve their products based on real user behavior.

Additionally, I gained experience troubleshooting a Next.js project by identifying missing configuration files and resolving issues related to project setup.

## What Was Hard

The most challenging part today was configuring PostHog without having a Project API Key. I also faced issues after copying my Next.js project, where some configuration files were missing, causing Tailwind CSS and other parts of the application to stop working correctly. Debugging these setup issues helped me understand the importance of project structure and configuration.
