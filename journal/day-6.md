# Day 6 – Daily Learning Journal

**Date**:27 July 2026

## What I Learned Today

Today I learned how to build a responsive web component using Tailwind CSS. I understood the concept of utility-first CSS, where small utility classes are used directly in HTML instead of writing custom CSS. I built a responsive product card and learned how to use Flexbox for aligning elements and Grid for creating structured layouts. I also practiced using Tailwind's responsive breakpoints like `sm`, `md`, and `lg` to make the component adapt to different screen sizes.

## What Was Hard

The most challenging part was remembering the different Tailwind utility classes and knowing when to use Flexbox versus Grid. Since I am more familiar with writing traditional CSS, it took some time to understand how multiple utility classes work together to create the desired design. I also spent time experimenting with responsive breakpoints to see how the layout changes on different screen sizes.

## One Question I Still Have

I understand how to build responsive components using Tailwind CSS, but I would like to know how large production projects organize and reuse Tailwind styles efficiently without making the HTML difficult to read and maintain.
