# Day 7 – Daily Learning Journal

## What I Learned Today

Today I built a small React application using Vite. I learned how React applications are organized into reusable components and how data can be passed between components using props. I also used the `useState` hook to manage state and update the user interface dynamically without refreshing the page. While building the counter application, I understood how state changes trigger React to re-render the component automatically. In addition to React concepts, I also learned how to troubleshoot Git issues after encountering a corrupted rebase state and safely recovered my repository without losing my work.

## What Was Hard

The most challenging part today was resolving the Git issue. Even though I had not intentionally started a rebase, Git reported that a rebase was in progress because of corrupted rebase metadata. It took some investigation to identify the problem and remove the stale rebase files safely. On the React side, understanding how props and state work together became much clearer after implementing them in the counter application.
