# Week 1 Review

## What I Learned This Week

This week was a great learning experience because I worked on different parts of full-stack development through daily hands-on tasks. I learned how to use Docker to containerize applications, build responsive user interfaces with Tailwind CSS, create React applications using components, props, and state, and develop modern web pages using Next.js.

I also explored PostHog analytics by integrating event tracking into a Next.js application and understood how user events and funnels help analyze user behavior. Later, I learned Prisma ORM by creating database models, defining relationships, running migrations, and querying data from a PostgreSQL database.

The biggest learning this week was understanding how a complete full-stack application works. I connected the frontend, backend, and database and understood the complete flow of data from the user interface to the API and finally to the database. I also learned how REST APIs exchange data using JSON and how React communicates with a Spring Boot backend.

Along with development, I improved my Git workflow by using conventional commits, organizing my repository properly, and maintaining daily journals and learning notes.

---

## Projects and Tasks Completed

- Built and ran a Docker container using a Dockerfile.
- Created a responsive component using Tailwind CSS.
- Developed a React application using components, props, and state.
- Built a responsive landing page using Next.js App Router.
- Integrated PostHog analytics and tracked custom events.
- Created a Prisma schema with models and relationships.
- Queried PostgreSQL data using Prisma Client.
- Connected frontend, backend, and database into a mini full-stack application.
- Updated documentation, learning notes, and daily journals throughout the week.

---

## What Was Challenging

This week came with several challenges. Setting up Docker for the first time and understanding images and containers took some time. While working with Git, I encountered rebase-related issues and learned how to resolve them safely.

I also faced problems configuring Next.js, integrating PostHog, and working with Prisma migrations. Understanding migration drift, unique constraint errors, and configuring a new Neon database helped me become more comfortable with backend development.

Another challenge was understanding how React and Spring Boot communicate while running on different ports and how data flows through the Controller, Service, Repository, and Database layers.

---

## Biggest Achievement

My biggest achievement this week was successfully building multiple mini-projects using modern technologies and understanding how they connect together. I successfully created a full-stack application where the frontend communicates with the backend API, which interacts with the PostgreSQL database to retrieve and store data.

I also became much more confident using Git, Docker, React, Next.js, Prisma, and Spring Boot together in a structured development workflow.
